# Documentation inventory and cleanup

Current entry points are [employee usage](claim_first.md), [architecture](architecture.md), [automatic assessment](automatic_claim_assessment.md) and [known limitations](known_limitations.md). The [structured-extraction experiment](structured_extraction_experiment.md) is disabled. Study review/adjudication guidance applies to Research/admin, not as a prerequisite for employee verdicts.

Superseded guidance is either archived in place with a status banner or retained byte-for-byte in [the archive](archive/pre-structured-extraction/README.md). Its [manifest](archive/pre-structured-extraction/manifest.json) records original paths and checksums. Current guidance removes the stale human-before-verdict requirement, obsolete 20/30 production packet sizes, old interpreter routing and old Git-environment claims. Historical counts, submitted portfolios, prior evaluation reports and development observations are retained, not rewritten as new results.

Inventory scope: repository Markdown visible to `rg`, excluding raw evidence and reference materials. Data, study artifacts and binary submitted records are protected by the experiment preservation manifest; they are not treated as current instructions. The [machine-readable inventory](../reports/structured-extraction-development/documentation-inventory.json) records file-level categories/checksums.
